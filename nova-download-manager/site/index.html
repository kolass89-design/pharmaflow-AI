Nova Download Manager

Fast, resumable downloads for Windows & Android — with honest browser media detection and a built-in player. No accounts. No telemetry. No ads. Just your files, on your device.

⬇ Download for Windows 🤖 Android APK 🧩 Browser extension

All builds are produced by GitHub Actions from this open-source code. Windows installer is unsigned (SmartScreen may warn); Android CI builds are debug-signed unless a release key is configured. Always download from the official Releases page.

⚡

Built for unreliable connections

Pause and resume with HTTP Range, automatic retries with backoff, and optional multi-segment downloading — every byte validated before a file is marked complete.

🎬

Detects real media files

The browser extension finds direct video/audio files as you browse and offers them in Nova — ask-first by default. Streaming and DRM-protected media is never scraped or bypassed.

▶️

Player included

Watch and listen right inside Nova: playlists, seek, speed control, fullscreen, and resume-where-you-left-off. Works with files already on your device, too.

🔒

Private by design

Local-only storage, a token-paired connection between browser and app, private-network blocking, and downloaded programs are never auto-run.

🗂️

Organized automatically

Categories for video, audio, documents and more; per-category folders; queue limits; scheduling; duplicate warnings; full history with search.

🪶

Lightweight

Streaming engine with bounded memory, a 15 KB browser extension, and a native Android app. Sensible defaults, no bloat.

Nova is open source (MIT). It downloads direct files; for platforms like YouTube or TikTok, please use their official offline features.
